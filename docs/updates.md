# starbaby Updates

## 0.1.0 (208)

Adds speaker controls beside the mini-player stars: Enable/Disable, live local and AirPlay speaker selection, individual volumes, and automatic 1.3-second lyric compensation while routing. Bundles the audio engine; standalone Airhead is not required. Speaker routing currently requires macOS 27 or later. Allow system-audio capture when prompted. Disable other routing apps before enabling.

Speaker-engine third-party licenses are included in the app. [Corresponding sources](https://github.com/squintgit/starbaby-releases/releases/tag/speaker-engine-11-sources).
